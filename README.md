## 🚀 What I'm Building

### [AI_Inference_Runtime](https://github.com/bilal-512/AI_Inference_Runtime)

A small **C++ AI inference runtime built from scratch** to understand how inference engines work internally.

Currently implementing the runtime foundation, including:

* Tensor abstraction
* Tensor memory and shape management
* Element access
* Operators
* MatMul
* ReLU
* GELU
* Operator testing
* CMake-based build system

The goal is to gradually evolve the project toward a small educational inference engine rather than relying entirely on existing frameworks.

---

### GPT-2 + ONNX + MLIR + IREE

Exploring the complete path from a trained model to a compiled inference artifact:

```text
Hugging Face / PyTorch
        ↓
      ONNX
        ↓
      MLIR
        ↓
      IREE
        ↓
   Compiled VMFB
        ↓
      Runtime
```

Working with **GPT-2**, ONNX export, MLIR representations, IREE compilation, and CPU/RISC-V execution.

---

### ResNet18 on RISC-V with IREE

Experimenting with deploying **ResNet18** through the IREE compiler stack and executing the resulting model on RISC-V.

Working with:

* ONNX
* MLIR
* IREE
* LLVM CPU backend
* RISC-V
* QEMU
* Model validation
* CPU vs RISC-V inference
